Windows 更新：
1. 先备份 GitHub Desktop 当前本地仓库。
2. 将本压缩包解压后的全部内容复制到本地 zero-carbon-park 目录并覆盖。
3. 不要删除本地 .git 文件夹。
4. GitHub Desktop 填写提交说明：全面升级页面、地图、报告与可行性分析。
5. 点击 Commit to main，再点击 Push origin。
6. 等待 GitHub Actions 全部变绿。
7. 打开公开网站并按 Ctrl+F5 强制刷新。
