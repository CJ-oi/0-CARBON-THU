## 六、邮件发送边界

GitHub Pages 本身不能安全保存邮件服务密钥。源码已提供两级方式：

1. 默认方式：打开用户电脑的邮件客户端，并自动写入收件人、主题和报告链接；
2. 直接发送方式：部署 Cloudflare Worker，并使用 Resend 发送固定路径的最新 PDF 附件。

直接发送需要一次性配置 Cloudflare、Resend、已验证发件域名和仓库密钥。未完成该配置时，网页不会假装已经发送成功。
