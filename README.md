# 园区碳观察

面向经济技术开发区的零碳园区公共数据、自动报告与项目可行性分析网站。

网站不是单个演示页面，而是一套可公开部署和持续更新的源码，包含公开来源采集、事件归并、园区名录、矢量地图、坐标审核、数据门槛、国家指标差距、减排建议、成本效益项目组合、报告截图、PDF 输出、可选邮件发送、自动测试和 GitHub Pages 发布流程。

## 五项实际工作

1. **数据够不够**：核对边界、企业清单、基准年、能源、排放、经济与项目参数；不足时生成补数任务。
2. **现状是什么**：形成园区资料画像和结构相似园区，不把结构相似度写成绩效排名。
3. **差距在哪里**：数据门槛通过后，按国家级零碳园区试行指标体系计算现状值、目标值和差距。
4. **怎么减**：把措施分为无悔型、条件型和战略型，根据指标差距形成可追溯的分级建议。
5. **花多少钱**：在预算、目标和项目参数约束下形成项目组合，输出投资、减排、净收益、成本和年度路径。

## 主要改进

- 在线浏览采用 Leaflet + OpenStreetMap，点位直接使用纬度和经度；网络不可用时回退到同坐标系简化矢量图；
- 79 个园区点位增加精度、来源、复核状态和复核日期；
- 标题、文号、规范 URL 和内容近似度共同用于事件归并；
- 日报和周报按园区建设、技术设施、项目投融资、政策标准和数据评估进行平衡；
- 周报增加数据质量摘要、主题结构、机会、约束和补数任务；
- 可行性报告自动插入首页、地图和五问工作台截图；
- 根据指标差距自动生成分级减排建议；
- 66 项措施默认分页展示，避免页面过长；
- 可选 Cloudflare Worker + Resend 将最新 PDF 发送到用户输入邮箱；未配置服务时安全回退到本机邮件客户端。

## 数据资产

- 67 个国内园区；
- 12 个国际参考案例；
- 50 项数据准备字段；
- 66 项减排设施指南；
- 15 条政策与核算规则；
- 滚动公开记录和来源健康台账；
- 79 条坐标审核记录；
- 可复现的示范可行性场景。

公开信息用于发现政策、园区实践和技术线索。正式核算必须使用同一园区边界、同一年度、可追溯的活动数据和原始材料。建设名单不等同于达标排名。

## 本地运行

需要 Python 3.11 或更高版本。

Windows：

```powershell
.\run.ps1
```

macOS / Linux：

```bash
./run.sh
```

随后打开 `http://127.0.0.1:8765`。

## 构建、截图和 PDF

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
zcpark build --output site --feasibility-input data/assessments/example.json
python scripts/capture_and_render.py --site site
zcpark validate --site site
node --check static/app.js
```

## GitHub Pages 自动更新

`.github/workflows/pages.yml` 支持：

- 推送到 `main` 后自动构建和发布；
- 每 6 小时检查公开来源；
- 去重、事件归并、来源健康和版本档案；
- 自动生成日报、周报和可行性报告；
- 自动截取页面并生成 PDF；
- 测试或质量检查失败时停止部署，保留上一版成功网站。

更新现有 Windows 仓库见 [docs/UPGRADE_WINDOWS.md](docs/UPGRADE_WINDOWS.md)。邮件发送见 [docs/EMAIL_DELIVERY.md](docs/EMAIL_DELIVERY.md)。

## 在线地图、报告截图与邮件发送

- 在线浏览时使用 Leaflet + OpenStreetMap，园区点位直接按经纬度落图；网络不可用时自动回退到同坐标系简化矢量底图。
- 坐标表记录点位精度、复核状态、来源和复核日期。点位是园区或所在片区近似中心，不替代法定四至边界。
- GitHub Actions 每次合格构建后自动截取首页、园区地图和五项工作界面，并嵌入日报、周报和可行性初筛报告。
- 可行性初筛同时输出数据门槛、指标差距、分层减排建议、预算约束项目组合、年度路径和关键参数敏感性。
- 邮件发送采用独立 Cloudflare Worker + Resend，避免把邮件密钥和收件地址写入公开仓库；未配置时网页自动使用本机邮件客户端发送报告链接。

第三方组件和地图数据许可见 `THIRD_PARTY_NOTICES.md`。
