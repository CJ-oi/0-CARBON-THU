# 使用说明

## 1. 网站用途

网站面向经济技术开发区和零碳园区建设，围绕五项实际工作组织数据：

1. 数据够不够；
2. 现状是什么；
3. 差距在哪里；
4. 怎么减；
5. 花多少钱。

公开信息用于发现线索、核对园区对象和补充证据，不代替园区正式台账。正式核算要求同一园区边界、同一自然年、统一单位和可追溯原始材料。

## 2. 园区地图

在线浏览使用 Leaflet + OpenStreetMap，园区点位直接按纬度和经度落图；网络不可用时自动切换为同坐标系简化矢量备用图。点击点位可查看：

- 园区名称、层级和产业；
- 经度、纬度和坐标精度；
- 坐标复核状态与来源；
- 建设周期和范围类型；
- 已核验的公开事实；
- 数据限制和原文入口。

点位是园区或所在片区的近似中心，只用于导航，不代表法定四至边界。发现错误时通过 GitHub Issue 提交正确坐标、边界或原始来源。

## 3. 近期动态

动态进入公开页面前经过：

- 相关性评分；
- 标题和文号规范化；
- 规范 URL 去重；
- 同一事件近似归并；
- 来源层级和记录完整度评分；
- 分类结构平衡。

同一事件的补充来源保留在主记录下，不重复占用版面。

## 4. 五问工作台

### 数据够不够

勾选已取得字段，计算数据准备度。缺失项自动形成补数任务，包含责任部门、最低材料和建议时限，可导出 CSV。

### 现状是什么

选择园区，从管委会、企业、能源运营、公共设施、监管评估和研究评估视角查看资料画像。结构相似园区只用于确定调研对象，不是绩效排名。

### 差距在哪里

确认边界和自然年后，录入能源、排放和资源循环数据。系统计算单位综合能耗碳排放和引导指标差距。未通过数据门槛时不输出达标结论。

### 怎么减

点击“根据差距生成建议”，系统把未达指标与措施库匹配，形成无悔型、条件型和战略型建议。每项建议列出前置数据、计算逻辑、经济性字段和主要约束。没有项目参数时不填写确定减排量。

### 花多少钱

录入项目投资、年度减排、年度节省、运维、寿命和证据等级，形成预算约束下的项目组合、年度路径和可行性初筛报告，并显示保守、基准和改善三种敏感性情景。只要入选项目仍含演示参数，页面会明确标记为演示场景，不形成正式可行性结论。

## 5. 报告

自动构建会生成日报、周报和可行性初筛报告。报告包含：

- 数据质量摘要；
- 分类结构和主题结构；
- 经过去重的重点记录；
- 经开区机会、约束和补数任务；
- 无悔工作清单；
- 首页、地图和五问工作台截图；
- 可行性场景下的指标差距、减排建议和项目组合。

报告提供 HTML、Markdown、JSON 和 PDF。

## 6. 邮件发送

未配置发送服务时，网页会打开本机默认邮件客户端并填入报告链接。部署 `services/report-mailer` 后，可以把最新 PDF 直接发送到用户输入的邮箱。详细步骤见 `docs/EMAIL_DELIVERY.md`。

## 7. 使用边界

网站用于公开数据治理、前期筛查和项目排序，不替代碳核查、节能审查、环评、电网接入审查、工程可研和投资决策。
