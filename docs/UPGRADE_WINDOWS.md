## 8. 出错处理

若 Actions 出现红色错误：

1. 点击失败的运行记录；
2. 打开红色步骤；
3. 复制最后 30 行日志；
4. 不要先自行删除数据文件；
5. 保存错误截图和本次提交编号。

地图点位、园区名称、来源或计算问题也可通过仓库中的 Issue 模板提交，并附上正确坐标、正式文件或原始来源。
