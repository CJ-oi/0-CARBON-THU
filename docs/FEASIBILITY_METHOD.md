# 零碳园区可行性初筛方法

## 1. 方法定位

可行性初筛用于在正式可研之前回答：数据是否够用、现状是否可核算、主要差距是什么、候选措施是否适用、预算内能够形成多大减排。它是项目筛选和调研工具，不是法定审查结论。

## 2. 五步方法

### 第一步：数据门槛

检查园区边界、企业清单、基准年、能源和排放。缺失时停止正式计算，生成责任明确的补数任务。

### 第二步：现状基线

建立排放清单、综合能源消费和经济产出基线；同时保留产业结构、能源基础设施、公共设施和利益相关方信息。

### 第三步：标准差距

将现状值与适用规则比较，分别记录现状、目标、差距、状态、数据来源和政策版本。不能确认适用范围的阈值标记为“待确认”。

### 第四步：措施筛选

按产业、对象、前置数据和实施约束筛选措施。优先考虑无悔型工作；条件型和战略型措施进入专项核查。

### 第五步：成本效益组合

使用可核验项目参数计算投资、减排、收益、运维、寿命和边际减排成本，再根据预算和目标选择项目组合。组合形成后同时计算保守、基准和改善三种透明敏感性情景，检查结论是否过度依赖单一参数。

## 3. 无悔型工作

无悔型工作通常对外部制度依赖较小，并可同时改善管理、成本或运行可靠性。典型内容包括：

- 边界、企业清单和计量体系；
- 电机、泵、风机和空压系统；
- 蒸汽管网、疏水和凝结水回收；
- 余热、余压和低品位热利用；
- 再生水和公共设施优化；
- 工业副产物协同；
- 设备维护、异常诊断和节能量测量验证。

“无悔”不等于不需要投资，而是指即使外部政策和能源价格发生变化，项目仍较可能保留运行或管理收益。

## 4. 绿电路径的条件

绿电采购、绿电直连、储能和微电网应至少核对：

- 可再生能源资源和发电曲线；
- 园区负荷曲线和直接消纳；
- 网架安全、电能质量和备用；
- 计量、结算和偏差责任；
- 项目投资、运营和合同主体；
- 绿色电力环境属性归属；
- 电价、输配费用和长期合同风险。

条件不完整时，只作为指南和专项可研任务，不进入确定性投资建议。

## 5. 参数证据等级

建议将项目参数分为：

1. **待核实**：只有项目名称或粗略设想；
2. **指南参数**：来自行业指南或相似案例；
3. **供应商报价**：有设备方案和报价，但尚未完成能量平衡；
4. **可研参数**：完成现场调查、能量平衡和工程方案；
5. **实测数据**：来自已实施项目或连续监测。

结果中应保留参数等级。指南参数和演示参数不得直接用于正式投资决策。

## 6. 结论分级

- **暂不具备正式测算条件**：数据门槛未通过；
- **具备初步测算基础，但关键风险尚未关闭**：存在高风险或目标缺口；
- **具备初步可行性，需专项可研和参数核验**：数据门槛通过，仍有中等风险；
- **具备较完整的初步可行性条件**：关键字段、项目参数和实施条件较完整。

## 7. 演示场景与正式初筛

演示场景用于检查数据结构、核算公式、项目组合和报告生成是否能够运行。演示场景可以填写完整字段，但其活动数据、报价、节能量和减排量不代表任何真实园区。只要入选项目仍使用“演示参数”，结论必须明确写为“不构成园区可行性结论”。

正式初筛至少需要园区原始台账、适用因子、项目报价或可研参数，以及可复核的测量验证边界。

## 8. 正式可研需要补充的工作

- 法定边界和企业清单确认；
- 基准年排放核查；
- 分时负荷和能源平衡；
- 设备台账及运行工况；
- 接入系统条件；
- 工程方案和施工条件；
- 投资报价、融资条件和税费；
- 节能量与减排量测量验证方案；
- 利益相关方合同与收益分配；
- 环评、安评、节能审查和其他合规程序。
