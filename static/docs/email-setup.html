报告邮件发送配置

GitHub Pages 不能安全保存邮件密钥。未配置发送服务时，网站会打开本机邮件客户端；配置 Cloudflare Worker 后，可以直接把最新 PDF 报告发送到用户输入的邮箱。

工作方式

  1. 网页只提交收件邮箱、报告类型和本次发送授权；
  2. Worker 校验来源、邮箱和报告类型；
  3. Worker 从本网站固定路径读取最新 PDF；
  4. 通过 Resend 发送附件；
  5. 邮箱不会写入 GitHub 仓库。

部署步骤

cd services/report-mailer
npm install
npx wrangler login
npx wrangler secret put RESEND_API_KEY
npm run deploy

将部署得到的 Worker 地址写入 config/runtime.json 的 mail_endpoint，提交并推送后网站自动重建。

必要配置

SITE_URL = "https://cj-oi.github.io/zero-carbon-park/"
ALLOWED_ORIGIN = "https://cj-oi.github.io"
REPORT_FROM = "园区碳观察 <reports@已验证域名>"

安全边界

不要将 Resend 密钥写入仓库。正式公开前建议启用发件域名 SPF/DKIM、Cloudflare Turnstile 和请求限流。服务不接受任意附件地址，只从本站固定报告路径读取 PDF。
