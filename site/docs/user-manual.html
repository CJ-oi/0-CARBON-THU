使用说明

网站围绕“数据够不够、现状是什么、差距在哪里、怎么减、花多少钱”组织工作。公开资料用于发现线索、核对对象和建立任务；正式核算只使用同一边界、同一年度、可追溯的园区数据。

园区地图

在线浏览使用 Leaflet + OpenStreetMap，点位直接按纬度和经度落图；网络不可用时自动切换为同坐标系简化矢量备用图。点位为园区或所在片区的近似中心，只用于导航，不代表法定四至。点击点位可查看经纬度、精度、复核状态、产业、建设周期、公开事实和来源。

近期动态与数据质量

动态先经过相关性筛选、标题规范化、事件归并和来源分级。相同事件的多个来源归并到一条主记录，补充来源仍保留。数据质量区展示实施类、政策类、重复合并、来源健康和正式核算门槛。

数据够不够

勾选已经取得的材料，系统按字段优先级计算准备度，并生成带责任部门、最低材料和建议时限的补数任务，可导出 CSV。

现状是什么

选择园区，从管委会、企业、能源运营、公共设施、监管评估和研究评估视角查看资料画像。结构相似园区只用于确定调研对象，不是绩效排名。

差距在哪里

确认边界和自然年后录入能源、排放和资源循环数据。系统计算单位能耗碳排放及引导指标差距；数据门槛未通过时不输出达标结论。

怎么减

点击“根据差距生成建议”，系统把未达指标对应到措施库，给出无悔型、条件型和战略型建议，并列出前置数据和限制。无项目参数时不填写确定减排量。措施库默认显示 12 项，可继续展开或按方向检索。

花多少钱

录入项目投资、年度减排、收益、运维、寿命和证据等级后，系统形成预算约束下的项目组合、年度路径和可行性初筛报告，并显示保守、基准和改善三种敏感性情景。只要入选项目仍使用演示参数，页面会明确标记为演示场景，不形成正式可行性结论。

报告与邮件

定时工作流自动生成日报、周报和可行性报告，并把首页、地图和五问工作台截图插入报告。未配置邮件服务时，发送按钮会打开本机邮件客户端；配置安全发送端点后可直接发送 PDF 附件。

数据更正

点击网站中的“提交数据更正”进入 GitHub Issues。请提供园区对象、正确经纬度或边界、原文入口、发布日期、建议修改内容和核验理由。不要上传企业敏感台账、合同价格或个人信息。

使用边界

网站用于公开数据治理、前期筛查和项目排序，不替代碳核查、节能审查、环评、电网接入审查、工程可研和投资决策。
